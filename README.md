# 직진 게임

방향을 한 번 정하면 벽이나 기믹을 만날 때까지 멈추지 않는 웹 퍼즐 게임입니다.

## 바로 플레이

- https://xn0220.github.io/straight-game/

## 난이도와 캠페인

- **쉬움 · 지구 궤도 연구실**: 기본 이동, 일방통행, 워프, 게이트, 회전, 위상 조합을 5개 맵씩 익히는 훈련 30개
- **화산 행성 아르코**: 신규 기믹 없이 벽과 이동 순서만으로 푸는 기본 직진 퍼즐 30개
- **바람 행성 에어론**: 표시 방향으로만 통과할 수 있는 일방통행 퍼즐 30개
- **균열 행성 넥서스**: 한 쌍의 공간을 연결하는 포탈 퍼즐 30개
- **발전 행성 볼테라**: 스위치를 작동해 잠긴 문을 여는 퍼즐 30개
- **결정 행성 샤디아**: 충돌하면 부서지고 이후 통과할 수 있는 파괴 블록 퍼즐 30개
- **기계 행성 기어라**: 진행 방향을 시계 방향으로 꺾는 회전 패드 퍼즐 30개
- **수정 행성 프리즘**: 두 색의 충돌 상태를 바꾸는 위상 전환 퍼즐 30개
- **웜홀 베타 · 곡률 행성 에테르**: 중심↔바깥 방사 이동과 시계·반시계 원주 이동을 사용하는 원형 실험 맵 30개
- **웜홀 베타 · 육각 성운 헥사리움**: 여섯 방향 직진과 포탈·위상 스위치를 사용하는 육각형 실험 맵 30개
- **웜홀 · 쌍성계 제미니아**: 하나의 입력으로 두 행성의 캐릭터를 함께 움직이는 동기화 퍼즐 30개
- **웜홀 · 중첩차원**: 같은 좌표의 현실·이면 차원을 전환해 서로 다른 벽을 통과하는 퍼즐 30개
- **웜홀 · 잔상은하**: 본체는 현재 입력, 잔상은 직전 입력을 수행하는 한 턴 지연 퍼즐 30개
- **웜홀 · 일식행성**: 방향 입력이 끝날 때마다 낮과 밤의 지형이 바뀌는 퍼즐 30개
- **웜홀 · 중력핵 행성**: 캐릭터와 모든 이동 블록이 동시에 미끄러지는 배치 퍼즐 30개
- **웜홀 · 뫼비우스 회랑**: 가장자리를 넘을 때 반대편의 뒤집힌 좌표로 연결되는 공간 퍼즐 30개

지구 훈련은 쉬움, 일곱 행성은 보통 난이도로 분리됩니다. 보통 난이도는 `기본 이동 30개 + 기존 기믹 6종류 × 30개`로 재구성되어, 지구 연구실을 플레이하지 않아도 각 행성 1단계에서 신규 기믹을 배울 수 있습니다. 1~10단계는 작은 맵, 11~20단계는 중간 맵, 21~30단계는 기존 크기이며 10·20·30단계는 보스 퍼즐입니다. 26~30단계는 각각 최소 20·22·24·26·30수입니다.

공식 240개 맵은 BFS 상태 탐색으로 클리어 가능 여부, 실제 최단 이동 수, 필수 신규 기믹 사용, 서로 다른 기믹 최대 2종류, 최단 경로 4개 이하를 자동 검증합니다. 각 행성 진행도는 따로 저장되며 이전 행성을 완주하지 않아도 자유롭게 시작할 수 있습니다.

웜홀 베타는 공식 캠페인과 기록을 분리합니다. 1~10단계는 작은 원형 입문 맵, 11~15단계는 확장 맵, 16~20단계는 순간이동 포탈 맵, 21~30단계는 포탈과 온오프 블록을 함께 쓰는 고난도 맵입니다. 30개 맵 모두 원형 좌표 전용 탐색기로 PAR와 필수 기믹 사용 여부를 검증합니다.

헥사리움은 1~5단계 1~3회, 6~10단계 3~5회, 11~15단계 5~10회, 16~20단계 10~15회, 21~30단계 8~20회의 최단 이동 범위를 자동 검증합니다. 21단계부터는 포탈, 26단계부터는 포탈과 위상 스위치를 함께 사용해야 풀리도록 구성됩니다. PC에서는 Q/E, A/D, Z/C 또는 숫자패드 7/9, 4/6, 1/3을 사용하고 모바일에서는 화면의 6방향 버튼을 사용합니다.

웜홀 선택 화면은 기존 3개 세계를 유지하면서 신규 5개 세계를 더한 8개 독립 캠페인, 총 240개 맵으로 확장되었습니다. 신규 세계는 고정 시드로 구성되어 접속할 때마다 맵이 바뀌지 않으며, 제작 과정에서 각 단계의 클리어 가능 여부, 실제 최소 조작, 고유 규칙 사용 여부, 보조 기믹 최대 2종류를 BFS로 확인했습니다. 플레이 중에는 검증된 결과만 불러오므로 별도의 실시간 탐색을 실행하지 않습니다. 10·20·30단계는 보스 테두리와 왕관으로 구분됩니다.

신규 세계에는 시간제한, 자동 이동, 시간이 지나면 바뀌는 상태, 무작위 결과가 없습니다. 모든 변화는 방향 입력, 차원 전환 버튼, 특정 타일 도착으로만 발생하며, 세계별 ID와 별도 저장 키를 사용해 기존 진행 기록과 충돌하지 않습니다.

## 플레이 기능

- 방향키·WASD·모바일 스와이프 및 화면 방향 버튼
- 한 수 되돌리기 버튼, U 또는 Ctrl+Z
- 맵별 별 1~3개와 개인 최고 기록 저장
- 최단 이동은 별 3개, PAR+10 이내는 별 2개
- 같은 맵에서 경계 충돌 3회 후 최적 경로 중간 지점 힌트 제공
- 첫 화면의 맵 선택·최근 맵 이어하기·게임 정보 분리
- 클리어 파티클·별 연출
- 픽셀 캐릭터 선택과 직접 편집
