# 직진 게임

방향을 한 번 정하면 벽이나 기믹을 만날 때까지 멈추지 않는 웹 퍼즐 게임입니다.

## 바로 플레이

- https://xn0220.github.io/straight-game/

## 난이도와 캠페인

- **쉬움 · 지구 궤도 연구실**: 기본 이동, 일방통행, 워프, 게이트, 회전, 위상 조합을 5개 맵씩 익히는 훈련 30개
- **벽돌 행성 아르코**: 기존 30개 맵과 일방통행·워프·스위치·파괴 블록
- **기계 행성 기어라**: 신규 30개 맵과 진행 방향을 시계 방향으로 꺾는 회전 패드
- **수정 행성 프리즘**: 신규 30개 맵과 두 색의 충돌 상태를 바꾸는 위상 스위치
- **웜홀 베타 · 곡률 행성 에테르**: 중심↔바깥 방사 이동과 시계·반시계 원주 이동을 사용하는 원형 실험 맵 30개
- **웜홀 베타 · 육각 성운 헥사리움**: 여섯 방향 직진과 포탈·위상 스위치를 사용하는 육각형 실험 맵 30개

지구 훈련은 쉬움, 기존 세 행성은 보통 난이도로 분리됩니다. 각 과정은 5개 맵씩 6개 구역으로 구성되며, 구역 안에서 난이도가 점차 높아집니다. 보통 난이도의 세 행성은 이전 행성을 완주하지 않아도 각 행성 1번 맵부터 시작할 수 있고, 행성 안의 진행도는 따로 저장됩니다. 총 120개 맵은 BFS로 최단 이동 수, 직선 이동 거리, 필수 기믹 사용 여부를 자동 검증합니다.

웜홀 베타는 공식 캠페인과 기록을 분리합니다. 1~10단계는 작은 원형 입문 맵, 11~15단계는 확장 맵, 16~20단계는 순간이동 포탈 맵, 21~30단계는 포탈과 온오프 블록을 함께 쓰는 고난도 맵입니다. 30개 맵 모두 원형 좌표 전용 탐색기로 PAR와 필수 기믹 사용 여부를 검증합니다.

헥사리움은 1~5단계 1~3회, 6~10단계 3~5회, 11~15단계 5~10회, 16~20단계 10~15회, 21~30단계 8~20회의 최단 이동 범위를 자동 검증합니다. 21단계부터는 포탈, 26단계부터는 포탈과 위상 스위치를 함께 사용해야 풀리도록 구성됩니다. PC에서는 Q/E, A/D, Z/C 또는 숫자패드 7/9, 4/6, 1/3을 사용하고 모바일에서는 화면의 6방향 버튼을 사용합니다.

## 플레이 기능

- 방향키·WASD·모바일 스와이프 및 화면 방향 버튼
- 한 수 되돌리기 버튼, U 또는 Ctrl+Z
- 맵별 별 1~3개와 개인 최고 기록 저장
- 최단 이동은 별 3개, PAR+10 이내는 별 2개
- 같은 맵에서 경계 충돌 3회 후 최적 경로 중간 지점 힌트 제공
- 첫 화면의 맵 선택·최근 맵 이어하기·게임 정보 분리
- 클리어 파티클·별 연출
- 픽셀 캐릭터 선택과 직접 편집
